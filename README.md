
# Mekalen Naidu – Personal Portfolio Website

This repository contains the source code for my personal portfolio website. The site showcases my work as a **Full Stack Developer and IT Technician**, highlights selected projects, and provides an easy way for visitors to get in touch.

The website is fully responsive, modern in design, and built with performance and usability in mind.

## 🧠 About the Website

This portfolio was designed to present both my **technical skills** and **problem-solving mindset**. It combines clean UI design with practical features such as theme toggling, smooth navigation, and a working contact form.

The site includes:

* A professional landing (hero) section
* An about section detailing my background and certifications
* A projects showcase with real-world work
* A functional contact form
* Light/Dark mode support
* Mobile-first responsive layout

---

## 🛠️ Technologies Used

* **HTML5** – Semantic and accessible structure
* **CSS3** – Custom styling, animations, and responsive layout
* **JavaScript (Vanilla)** – Interactivity, navigation, theme toggle, and UI behavior
* **Formspree** – Contact form handling
* **GitHub Pages** – Deployment and hosting

## 🚀 Getting Started

To run this project locally:

1. Clone the repository

   ```bash
   git clone https://github.com/mekalen/mekalen.github.io.git
   ```

2. Navigate to the project folder

   ```bash
   cd mekalen.github.io
   ```

3. Open `index.html` in your browser
   *(No build tools or dependencies required)*
